
# Afficionado Coffee Roasters - Data Driven Forecasting & Peak Demand Prediction

## Project Overview
This project predicts store-level coffee sales demand and peak-hour traffic using machine learning and time-series forecasting techniques.

## Features
- Store-wise sales analysis
- Revenue forecasting
- Peak demand prediction
- Hourly demand heatmaps
- Forecast comparison charts
- KPI dashboard
- Interactive Streamlit frontend

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
- Statsmodels

## Run the Project

### Step 1
Install dependencies:
```bash
pip install -r requirements.txt
```

### Step 2
Run the application:
```bash
streamlit run app.py
```

## Dataset
Dataset included inside:
